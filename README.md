# Swag Lab Cucumber Playwright

Cucumber + Playwright acceptance tests for the SauceDemo (Swag Labs) demo e-commerce website.

## Project structure

- `tests/acceptance/` — Cucumber feature files and step definitions
- `cucumber.conf.js` — Cucumber test runner configuration

## Running the tests

```bash
npm install
npx cucumber-js
```

## Tech stack

- Cucumber
- Playwright
